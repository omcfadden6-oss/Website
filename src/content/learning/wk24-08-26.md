## Did I achieve last weeks goals?
My goals last week were to finish the Monaco analysis project and make a start on this website - which I did! I did decide to ditch the preview for the Dutch GP that I was writing - once I realised the website would not be ready until after the race had taken place, it felt more relevant to write a race review instead.

## Goals for the week
Write an analysis/review of the Dutch GP, and hopefully get the website completed, or close to being completed.

## What I worked on
- **Wrote a race review for the Dutch Grand Prix** - analysed the strategy calls from the top teams, the performance of the substitute and standout midfield drivers, and the frustrations within the latter teams. I usually don't consider myself to be a "writer" by any stretch, but I always find it much easier when I have a genuine interest and something to say about what I am writing about. I wanted to make sure my writing was as fair and objective as possible.

- **Continued building this website** - in building this website, all the HTML I learned in high school started coming back to me! I tried to keep it as simple as possible, with a little hint of my own personality (hence the pink accents). I just want it to be as easy to find things as possible. 

### More on this website
I do find it's very easy to get caught up in all the little tweaks; make this font size bigger, move this 2 pixels to the left etc. I will admit building this website took me longer than expected, but I am really pleased with the result, and the overall structure does make it a lot easier to update. I have it set so that I can simply add a new project/article/log entry as a markdown file in their respective folders and it will appear on the site all nicely formatted! I really like that I can do all of this in markdown - it just feels nice and simple to me. The dynamic content on the home page was very satisfying to run as well.
